Tracklog

Your Apple Music library, turned into a SQL database.

Get your library file

  1. Open the Music app on your Mac.
  2. Choose File → Library → Export Library… in the menu bar.
  3. Save it. You'll get a file called Library.xml.
  4. Drop that file in the box here.
  1. Open iTunes on your PC.
  2. Choose File → Library → Export Library… (press Alt if the menu bar is hidden).
  3. Save it as XML. You'll get a file like Library.xml.
  4. Drop that file in the box here.

Play counts include your iPhone's plays when Sync Library is turned on. The export needs a computer; the iPhone app can't make one.

Analyze it

Your file never leaves this page. A SQLite database is built and queried right here in your browser.

Tables you can query
Tracklog builds a SQLite database with sql.js and runs every card as a SQL query. Open "Show SQL" on any card to see how it was calculated.
